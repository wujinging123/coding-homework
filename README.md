# coding-homework
分支是代码主线分出的独立副本，可以单独修改代码而不影响主代码；合并就是把分支上修改好的内容合并到主分支
##命令行
cd:切换当前所在文件夹
ls：列出当前文件夹里面所有文件
mkdir：新建文件夹
git add：将文件改动加入暂存区
git commit：保存改动，生成版本记录
git push：把本地代码上传到远程GitHub仓库
## 信息与安全意识
1. 许可证：这个项目选用MIT协议。它比较简单宽松，别人可以查看、使用我的代码，只需要保留版权信息，很适合我这个个人学习主页。
2. 我已经开启GitHub两步验证，登录账号时除密码外还需要验证码，保护账号安全。
3. AI曾经告诉我，网页里链接PDF直接填raw长链接就行。我自己试了之后发现这种链接容易失效，查资料了解到，直接写仓库内相对路径 profile.pdf 会更加稳定。
## 代码逻辑说明
1. `<a href="profile.pdf">` 是网页的跳转标签，href写文件位置，点击文字就能打开PDF简历。
2. `<style>` 用来写样式，调整网页背景、字体和颜色，不用改动文字内容，就能美化页面。
## 小游戏：贪吃蛇
### 阶段一：手动游玩版本
这是用HTML+CSS+JavaScript做的网页贪吃蛇游戏。用键盘方向键控制蛇移动，吃到红色食物蛇就变长。撞到墙或者撞到自己身体，游戏就结束。
游戏可以记录当前得分，还能保存最高分，关掉网页最高分也不会消失，也有重置游戏的按钮。
### 阶段二：AI自动演示
AI的逻辑很简单：蛇头朝着食物的方向移动。点击“开启AI自动”，蛇就会自己去找食物。
可以连续吃掉15个食物，不会死掉。
### 提示词迭代记录
1. 第一次：写网页贪吃蛇，方向键控制，计分、保存最高分，带重置按钮。
2. 第二次：在上面基础上，增加AI自动，蛇自己找食物，加开关按钮。
