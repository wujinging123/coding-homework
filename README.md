## 小游戏：贪吃蛇
### 阶段一：手动游玩版本
这是用HTML+CSS+JavaScript做的网页贪吃蛇游戏。用键盘方向键控制蛇移动，吃到红色食物蛇就变长。撞到墙或者撞到自己身体，游戏就结束。
游戏可以记录当前得分，还能保存最高分，关掉网页最高分也不会消失，也有重置游戏的按钮。
### 阶段二：AI自动演示
AI的逻辑很简单：蛇头朝着食物的方向移动。点击“开启AI自动”，蛇就会自己去找食物。
可以连续吃掉15个食物，不会死掉。
### 提示词迭代记录
1. 第一次：写网页贪吃蛇，方向键控制，计分、保存最高分，带重置按钮。
2. 第二次：在上面基础上，增加AI自动，蛇自己找食物，加开关按钮。
### AI给过但查证后认为是错误的信息
一开始AI告诉我，贪吃蛇AI只需要判断蛇头坐标大于食物坐标就可以移动。经过测试，这个逻辑是错的。
问题：只单纯比较大小，蛇会直接穿墙，遇到障碍物不会避让，很快就死亡。
查证：贪吃蛇不能只单向比较坐标，需要持续判断蛇头和食物的x、y两个方向，优先选择距离更近的方向移动。
### AI生成代码关键逻辑解释
1. 得分与最高分保存逻辑
每次吃到食物，当前得分加1。如果当前得分超过历史最高分，就把最高分保存到浏览器本地存储。就算关闭网页再重新打开，最高分数据也不会丢失。点击重置按钮，当前分数清零，重新开始游戏。

2. AI自动寻食逻辑
AI会对比蛇头坐标和食物坐标。优先先对齐X轴（左右方向），X坐标相同再对齐Y轴（上下方向），朝着食物方向移动。这个简单逻辑可以保证蛇连续吃到15个食物而不死。
